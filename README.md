
# Basic Python Chatbot

## About
This is a simple rule-based chatbot built using Python.
It responds to user messages with predefined replies.

## Features
- Responds to greetings
- Answers basic questions
- Displays current date and time
- Provides help instructions
- Exits when the user types "bye"

## Technologies Used
- Python
- Random module
- Datetime module

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python BasicChatbot.py

## Example
You: hello
Chatbot: Hi there!

You: what is the time
Chatbot: Current time is displayed.

You: bye
Chatbot: Goodbye! Have a great day!
